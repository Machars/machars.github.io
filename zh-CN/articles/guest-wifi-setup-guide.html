访客网络(Guest WiFi)：保护隐私的家门第二道锁

客人来了连WiFi怕泄露NAS里的隐私？访客网络自动隔离内网，还能给IoT设备一个安全的专属网络。

为什么你需要访客网络？

场景：一场聚会的安全隐患

周六晚上，你在家办生日聚会，20个朋友连上了你家WiFi。其中一位朋友的手机不知什么时候装了恶意APP——这个APP通过WiFi自动扫描，发现了你家的群晖NAS，开始暴力破解登录密码。因为你没开启自动封锁，三天后NAS被勒索病毒加密。

如果你开了访客网络——这些设备连不到NAS。因为访客网络和主网络是完全隔离的。

访客网络做什么？

连到访客网络的设备：

  • ✅ 可以正常上网
  • ❌ 看不到你家里的NAS、共享文件夹
  • ❌ 看不到你的电脑、手机
  • ❌ 无法登录路由器后台
  • ❌ (开启AP隔离后) 彼此之间也无法互相访问

访客网络的六大应用场景

场景配置建议
---------------
家里来客人临时开启，设2小时有效期
出租/民宿长期开启，限速防滥用
IoT设备专用智能家居全连访客网络，隔离主网络
工作室/小公司客户WiFi与内部网络分离
孩子设备隔离孩子设备连访客网络，限制时段
智能电视限制电视连访客，防厂商收集家庭网络数据

各品牌设置速查

品牌设置位置特色功能
------------------------
小米APP → 工具箱 → 访客WiFi可设限速和定时关闭
华为APP → 路由器 → 访客WiFi二维码分享、免密模式
TP-LINK后台 → 无线设置 → 访客网络2.4G/5G各一个
华硕后台 → 一般 → 访客网络最多3个访客网络
网件后台 → 基本 → 访客网络Orbi卫星也可独立开

IoT设备专用网络（高级玩法）

SSID 分配建议：
MyHome (主网络)     → 你的手机、电脑、NAS
MyHome-IoT (访客)   → 智能灯泡、插座、摄像头、音箱
→ IoT设备即使被攻击，也无法感染你的电脑和NAS

安全设置清单

  • [ ] 禁止访客网络访问内网（这是核心价值）
  • [ ] 开启AP隔离（访客设备之间不互通）
  • [ ] 设置有效期（避免忘记关闭）
  • [ ] 使用不同密码（不要和主网络相同）
  • [ ] 开启限速（防止客人占满带宽）

🎯 一句话：访客网络是路由器最被低估的功能。用好了，安全性和便利性双提升；不用，你的NAS对每个连上你家WiFi的人都是敞开的。
