一句话理解WAN/LAN口速率

场景：接口速率 = 水管的瓶颈

你家接了粗水管（1000M宽带），但水表（WAN口）只有细口径（100M），水流到后面还是细的。

1000M宽带 + 百兆口路由器 = 永远跑不过100M，就像F1赛车被限速到电动自行车。

这就是很多人的真实遭遇：办了千兆宽带，网速测出来不到100M——因为路由器WAN口是百兆的。

百兆口 vs 千兆口 vs 2.5G口

接口规格最高速度折算MB/s状态
-----------------------------------
百兆口(Fast Ethernet)100Mbps~12MB/s已淘汰，别买
千兆口(Gigabit Ethernet)1000Mbps~125MB/s当前主流，够用
2.5G口2500Mbps~312MB/s高端路由器，战未来
万兆口(10G)10000Mbps~1250MB/s企业级，普通家庭用不上
真实案例——"千兆路由器"的陷阱

小明在线买了台"1200M无线双频路由器"：

  • 商品标题：1200M
  • WiFi速率：2.4G(300M) + 5G(867M) = 1167M ≈ "1200M"
  • WAN口：百兆（100M）
  • 结果：WiFi再快，出口只有100M——下载永远不超过12MB/s
关键教训： "1200M/3000M"是WiFi理论速率（含夸大），WAN口速率才是真实瓶颈。买路由器要看清参数："WAN口：千兆"！

如何判断你的路由器是百兆还是千兆？

方法一：看接口标识
  • 千兆口通常标"1000M"、"Gigabit"、"GE"
  • 百兆口标"10/100M" 或什么都没标
  • 有些用颜色区分（但各厂商不同，不绝对可靠）
方法二：电脑插网线查看 
Windows: 设置 → 网络和Internet → 以太网 → 查看"链接速度"
显示1000/1000 Mbps → 千兆 ✅
显示100/100 Mbps → 百兆 ❌
方法三：路由器后台

系统状态/接口信息 → WAN口速率 → 显示1000M Full或100M Full

如果WAN口只有百兆怎么办？

场景：办了300M宽带，测速只有90M
诊断：路由器WAN口百兆 → 瓶颈
解决：换全千兆口路由器（200-500元）

检查链路——任何一个环节是百兆就受限：
光猫网口 → 路由器WAN口 → 路由器LAN口 → 电脑网口 → 网线
↑ 全部都要千兆，缺一不可！

常见坑：

  • 网线是4芯线 → 最高100M（要换8芯超五类/六类线）
    • 

  • 光猫是百兆口 → 致电运营商免费换千兆光猫
    • 

  • 老电脑只有百兆网卡 → 买个USB千兆网卡（几十块）
    •

🔌 核心记忆： 千兆宽带要看WAN口——百兆口=限速100M，千兆口=跑满1000M。买路由器避开"1200M无线+百兆口"的坑货，认准"全千兆口"。光猫→网线→路由器→电脑全部千兆才能跑满。
