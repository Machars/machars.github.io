DHCP是什么？用"酒店入住"理解

场景：入住酒店

你(设备)进入酒店(连接WiFi) → 前台(DHCP服务器)自动给你房卡(IP地址: 192.168.1.105) → 同时告诉你WiFi密码(子网掩码)、酒店大门(网关)、周边地图(DNS) → 你的行李(数据)就能顺利送达房间。

退房(断开WiFi) → 房卡回收(IP释放)，下一个客人用。

家用IP规划方案（最佳实践）

IP范围用途示例
--------------------
.1路由器网关192.168.1.1
.2-.9交换机、AP等网络设备.2是交换机
.10-.49固定分配的"VIP设备"NAS(.10)、打印机(.11)、摄像头(.12)
.50-.99预留(未来扩展)—
.100-.199DHCP自动分配池手机、笔记本随机获取
.200-.254实验/临时测试用

三种IP分配方式对比

方式一：DHCP自动分配（默认，省事）

→ 设备连上自动拿IP，但IP可能会变

方式二：DHCP地址保留（推荐！）

→ 在路由器上绑定MAC地址，同一设备永远拿同一IP

操作：路由器后台 → DHCP → 地址保留/静态分配
添加：NAS的MAC地址 + 指定IP(192.168.1.10)
→ NAS每次连网IP都是192.168.1.10
方式三：设备手动设IP（可靠但麻烦）

→ 在设备上手动填IP、掩码、网关、DNS

→ 换网络需要重新配置

IP冲突排查

症状： 突然上不了网、间歇性断网、某个设备网络异常 原因： 两台设备用了同一IP 解决：

``bash

# Windows查看局域网设备

arp -a

# 释放并重新获取IP

ipconfig /release && ipconfig /renew


确保DHCP地址池和手动固定IP不重叠！


多路由器环境不冲突

规则：一个家庭有且只有一台DHCP服务器(主路由器)

光猫是路由模式？→ 关掉光猫DHCP或改桥接

副路由做AP？→ 关掉副路由DHCP

Mesh系统？→ 子节点自动不参与DHCP

``

📋 管理建议： 建个表格记录所有手动分配IP的设备。换路由器时照表重建DHCP保留，无缝迁移。
