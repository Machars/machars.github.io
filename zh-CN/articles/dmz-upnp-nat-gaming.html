NAT类型：联机游戏的"社交等级"

场景：为什么匹配不到人？

你玩Switch的Splatoon 3，朋友的NAT类型是A(开放)，你是D(严格)。朋友能匹配全球10000人在线——你只能匹配同是D类型的500人。排位赛等10分钟进不去。

NAT类型SwitchPSXbox联机体验
-------------------------------------
完全开放ANAT1开放✅ 连所有人
中等BNAT2中等⚠️ 不能连"严格"
严格C/DNAT3严格❌ 只能连"开放"

改善NAT类型的三步方案

第一步：UPnP（最简单，推荐先试） 
路由器后台 → 安全/高级 → UPnP → 开启
游戏主机网络设置 → 自动 → 重启主机
→ NAT应为B/NAT2/中等（够用了）
第二步：手动端口转发（UPnP不够时）

PS5端口：

TCP: 80, 443, 3478, 3479, 3480
UDP: 3478, 3479

Switch端口：

TCP: 6667, 12400, 28910, 29900, 29901, 29920
UDP: 1-65535(实际UPnP自动处理即可)
  • 给游戏主机DHCP保留固定IP(如192.168.1.50)
  • 逐一添加上述端口转发到主机IP
  • 重启主机检查NAT
第三步：DMZ（最后手段，效果最强） 
路由器后台 → DMZ主机 → 填入游戏主机IP(192.168.1.50)
→ NAT变为A/NAT1/开放
⚠️ 只用游戏主机！不要放电脑！游戏主机有系统级安全保护

多层NAT：最容易被忽略的元凶

症状：所有方法试了NAT还是严格
原因：光猫也在做路由(双层NAT！)
检查：路由器WAN口IP是192.168.x.x → 光猫未桥接
解决：致电运营商"请把光猫改成桥接模式"

各平台NAT检测位置

  • Switch： 系统设置 → 互联网 → 测试连接
  • PS5： 设定 → 网络 → 查看连接状态
  • Xbox： 设定 → 一般 → 网络设置

UPnP安全提醒

定期检查UPnP映射表：

TP-LINK: 高级设置 → UPnP → 查看映射表
华硕: 系统记录 → 端口转发 → UPnP列表
发现不认识的映射 → 删除 → 不影响使用就别管

🎮 联机最佳实践： 光猫桥接 → 路由器拨号 → 游戏主机固定IP → 开UPnP。95%情况下NAT就是开放/中等。剩下5%上端口转发或DMZ。
