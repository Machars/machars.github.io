什么是QoS？用"交通管制"理解

场景：一个没有红绿灯的十字路口

没有QoS的路由器 = 一个没有红绿灯的十字路口。谁抢到路权谁走。一台电脑开BT下载，能把100%带宽吃光，其他人连网页都打不开。

有QoS的路由器 = 有个智能交警在路口指挥：

  • 🎮 游戏流量 → 警车🚔(优先通行，延迟最重要)
  • 📞 视频会议 → 救护车🚑(高优先级)
  • 📺 看视频 → 公交车🚌(正常通行)
  • 📥 下载 → 大货车🚛(排队等，慢一点没关系)

实战：华硕Adaptive QoS

后台 → Adaptive QoS → QoS → 开启
关键一步：手动填入实测带宽(去speedtest.net测)
  下行：200Mbps  上行：20Mbps
优先级拖拽排序：
  游戏 → 最高 | 影音 → 高 | 网页 → 中 | 下载 → 低
实测效果： 200M宽带，无QoS时有人满速下载 → ping百度300ms+。开启QoS后同样满速下载 → ping百度12ms。效果天壤之别。

手动限速（最直接的方案）

设备的合理限速：
你的电脑 → 不限 | 老婆手机 → 不限(家庭和谐)
孩子平板 → 30Mbps(够看网课) | 租客手机 → 20Mbps
BT下载机 → 50Mbps(重点限制上行) | 访客网络 → 10Mbps

SQM：OpenWrt的终极QoS

``bash

opkg update

opkg install luci-app-sqm

``

SQM使用cake算法，即使满速下载，延迟也能保持在10ms以内——这是传统QoS做不到的。

⚠️ 重要： QoS会消耗CPU。千兆宽带需要中高端路由器(华硕AX86U/小米AX9000级别)。500M以下宽带随便开。如果你只有1-2个人用且不打游戏，不需要QoS。
