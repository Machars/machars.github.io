一、登录管理后台

登录地址

  • 域名方式：tplogin.cn（推荐）
  • IP方式：192.168.0.1 或 192.168.1.1

登录步骤

  • 确保设备已连接路由器网络
  • 打开浏览器输入地址
  • 输入管理员密码
  • 点击"登录"

> ⚠️ 如果忘记管理员密码，只能按住Reset孔恢复出厂设置

二、界面概览

顶部导航

  • 网络状态：查看设备连接数、网速
  • 设备管理：查看和管理已连接设备
  • 高级设置：WiFi、安全、转发等设置

常用功能入口

  • 网络设置 → 上网设置
  • 无线设置 → WiFi名称密码
  • 设备管理 → 已连接设备列表

三、基础设置

修改管理员密码

高级设置 → 系统管理 → 修改登录密码

修改时区

高级设置 → 系统管理 → 时间设置 → 选择 GMT+8

固件升级检查

高级设置 → 系统管理 → 固件升级 → 检查更新

四、安全提醒

  • 管理员密码不要和WiFi密码相同
  • 关闭"远程管理"（除非你需要外网管理）
  • 定期检查固件更新
