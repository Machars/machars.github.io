LAN vs WAN：内网和"外网"到底什么意思？

一句话理解LAN和WAN

场景：LAN = 你家小区，WAN = 小区外面的世界
  • LAN（局域网） = 你家+邻居组成的封闭小区 —— 小区内部随便串门（设备之间自由通信），不用出小区大门
  • WAN（广域网） = 小区大门外面的整个城市 —— 想出去就得从大门过（经过路由器/网关），去外面上班、购物、玩耍

路由器上的接口：

[WAN口：蓝色/独立颜色] → 接光猫 → 去互联网
[LAN口：黄色/同色×4]   → 接电脑/电视/NAS → 在家内部

内网通信 vs 外网通信

真实案例——为什么投屏不需要互联网？

你把手机视频投屏到电视上，发现明明断了外网（没交宽带费）但投屏还是好好的。

因为手机→电视的数据走的是内网：

手机(192.168.1.5) → 路由器 → 电视(192.168.1.8)

数据根本没出你家路由器！就像在小区里串门不需要出小区大门。

但如果你想看B站视频：

手机(192.168.1.5) → 路由器 → 光猫 → WAN口 → 互联网 → B站服务器

数据出了小区大门（WAN口），就需要互联网（宽带）了。

路由器接口详解

接口颜色数量接什么方向
--------------------------------
WAN口蓝色/黄色/独立1个光猫通外网
LAN口黄色/黑色1-4个电脑/NAS/电视局域网内
USB口黑色0-2个打印机/硬盘共享存储

内外网的速度差异

内网传输速度 = 路由器LAN口速度（通常1000Mbps）
举例：电脑传文件到NAS → 最高约125MB/s（千兆路由）

外网下载速度 = 宽带套餐速度（如100Mbps）
举例：从网上下载文件 → 最高约12.5MB/s

内网比外网快很多！
这就是为什么NAS要接LAN口而不是走外网访问。

NAT和WAN/LAN的关系

回顾NAT的概念：NAT是路由器在LAN（内网）和WAN（外网）之间的"门禁系统"，负责两个世界的地址翻译和通行管理。

🏠 核心记忆： LAN=你家内部网络（小区），WAN=通往互联网（出小区大门）。路由器WAN口（通常蓝色）接光猫上网，LAN口（通常黄色）接家里设备。内网传输极快且不需要互联网。
