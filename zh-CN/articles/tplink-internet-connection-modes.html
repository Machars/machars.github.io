一、为什么会有三种上网方式？

设置路由器时，第一步通常就是选“上网方式”。很多人卡在这里不知道该选什么。

一句话理解：上网方式 = 你的宽带运营商用什么方式把网络送到你家
  • PPPoE → 运营商给了你一个“账号+密码”（像登录QQ）
  • 动态IP(DHCP) → 插上就能用，不需要账号密码（像插U盘）
  • 静态IP → 运营商给你一张写着IP地址的纸条（像固定门牌号）

> 🎯 选错上网方式 = 上不了网。下面逐个详解。

二、PPPoE（宽带拨号）— 最传统、最常见

什么是PPPoE？

PPPoE（Point-to-Point Protocol over Ethernet）就是“宽带拨号”。你的路由器需要像拨电话一样向运营商的服务器“拨号”，输入账号密码验证通过后才能上网。

什么情况下选PPPoE？

选PPPoE的场景

✅ 光猫是“桥接模式”（光猫只负责光电转换，不拨号）

✅ 运营商给了你宽带账号和密码

✅ 你自己用路由器拨号（路由器WAN口连光猫LAN口）

✅ 取消“光猫拨号”改“路由器拨号”后

❌ 光猫已经拨号了（光猫=路由模式），路由器选“动态IP”即可

设置步骤

  • 登录 tplogin.cn → 网络设置 → 上网设置
  • 上网方式选择「宽带拨号(PPPoE)」
  • 输入运营商提供的宽带账号和宽带密码
  • 点击保存

> ⚠️ 宽带账号密码不是WiFi密码！如果忘记了可以打运营商客服电话查询（电信10000/联通10010/移动10086）。

PPPoE 常见问题

问题原因解决
------------------
拨号失败/错误651账号密码错误重新输入，注意大小写
错误691账号被占用（已在别处拨号）等待1分钟后重试
错误678远程服务器无响应检查光猫是否正常工作
经常断线重拨线路不稳定联系运营商检修

三、动态IP（DHCP）— 最简单、插上就用

什么是动态IP？

动态IP就是你的路由器从上一级设备（通常是光猫）自动获取IP地址，不需要任何账号密码，就像插U盘一样“即插即用”。

什么情况下选动态IP？

选动态IP(DHCP)的场景

✅ 光猫是“路由模式”（光猫自己已经拨号了）

✅ 路由器WAN口插在另一个路由器LAN口下（二级路由）

✅ 校园网/公司网络（上级设备已分配IP）

✅ 大部分家庭宽带的默认场景（光猫拨号+路由自动获取）

> 📊 实际上80%的家庭宽带都是这种模式：光猫拨号 → 路由器自动获取IP。这也是为什么大多数新路由器拆开插上就能用。

设置步骤

  • 登录 tplogin.cn → 网络设置 → 上网设置
  • 上网方式选择「自动获取IP地址(DHCP)」
  • 保存即可（不需要填任何东西）

DHCP模式的隐藏坑：双层NAT

当你用“光猫拨号+路由器DHCP获取”时，实际上形成了两层NAT：

外网 → 光猫(NAT层1) → 路由器(NAT层2) → 你的设备

这会导致：

  • ❌ 端口转发、DDNS、远程访问变得困难
  • ❌ 游戏联机NAT类型变严格
  • ❌ 某些P2P应用速度受影响

🔧 解决方案：让光猫改“桥接模式”，由路由器自己PPPoE拨号。打运营商客服电话说“请把光猫改成桥接模式”即可。

四、静态IP（固定IP）— 手动指定、极少使用

什么是静态IP？

运营商分配给你一个固定不变的IP地址，你需要手动输入到路由器中。就像门牌号永远不会变，别人永远可以通过同一个IP找到你。

什么情况下选静态IP？

选静态IP的场景

✅ 企业/商铺宽带（运营商给了固定IP的纸条）

✅ 校园网需要手动配IP

✅ 特殊行业（监控、服务器需要固定公网IP）

✅ 部分酒店/公寓网络

❌ 普通家庭99%用不到！就算你有公网IP，也是PPPoE拨号获取的动态公网IP

设置步骤

  • 登录 tplogin.cn → 网络设置 → 上网设置
  • 上网方式选择「固定IP地址」
  • 填写运营商提供的四样信息：
项目示例说明
------------------
IP地址123.45.67.89你的固定公网IP
子网掩码255.255.255.0通常是这个
默认网关123.45.67.1运营商的网关地址
DNS服务器114.114.114.114可以用公共DNS

> ⚠️ 四样信息一个都不能填错！错一个就上不了网。

五、上网方式快速选择决策树

你收到了宽带账号+密码？
├── 是 → 选 PPPoE
└── 否 → 你收到了写着IP的纸条？
    ├── 是 → 选 静态IP
    └── 否 → 选 动态IP(DHCP)
三句话记住：
  • 有账号密码 → PPPoE（宽带拨号，最传统）
  • 什么都没给 → 动态IP（光猫已拨号，插上就用）
  • 给了IP纸条 → 静态IP（企业宽带，极其少见）

六、特殊场景：二级路由器怎么设置？

场景：家里加一个路由器扩展信号

假设主路由器是192.168.0.1，现在要加一个TP-LINK做二级路由：

方案A：WAN口接主路由LAN口

  • 上网方式选「动态IP」
  • 二级路由会自动获取192.168.0.x的IP
  • 缺点：主路由和二级路由的设备不在同一网段，互相看不到

方案B：LAN口接主路由LAN口（推荐！）

  • 先把二级路由LAN口IP改成192.168.0.2（和主路由同网段）
  • 关闭二级路由的DHCP服务器
  • 这样所有设备都在同一网段，互访无障碍
  • 实际上就是把二级路由当“交换机+AP”用

七、MAC地址克隆 — 换路由器上不了网的救星

有些运营商（尤其是部分地区的电信和校园网）会把宽带账号绑定到你旧路由器的MAC地址。换新路由器后，即使账号密码正确也拨不上号。

真实案例：

小明换了新TP-LINK路由器，PPPoE账号密码都填对了，却一直显示“连接失败”。打电话问运营商，对方说“没有限制”。折腾半天发现：旧路由器的MAC地址被运营商绑定了。

解决：在TP-LINK后台 → 网络设置 → MAC克隆 → 把旧路由器的MAC地址填进去 → 保存。马上就能拨号了。

操作步骤

  • 登录 tplogin.cn → 网络设置 → 上网设置
  • 找到「MAC克隆」选项
  • 选择“使用自定义MAC地址”
  • 输入旧路由器的MAC地址（旧路由器底部标签上有）
  • 保存并重启

> 💡 如果你不知道旧路由器的MAC，也可以选“克隆本机MAC”，用当前电脑的MAC去拨号。

八、三种上网方式对比总结

对比维度PPPoE动态IP(DHCP)静态IP
--------------------------------------

需要手动填IP❌❌✅ 需要

家庭用户比例~15%~84%~1%
IP会不会变每次拨号可能变可能变永远不变

🎯 核心记忆：

  • 有账号密码就选PPPoE — 输入运营商给的宽带账号密码
  • 什么都没给就选动态IP — 光猫已经帮你拨号了
  • 给了IP纸条才选静态IP — 普通家庭用不到
  • 换路由器上不了网试试MAC克隆 — 旧MAC被运营商绑定了
  • 想远程访问NAS/监控 → 光猫改桥接+路由器PPPoE拨号 — 获取公网IP
