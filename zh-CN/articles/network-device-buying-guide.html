家庭网络的数据流： 
光纤进户 → [光猫] → [路由器] → [交换机(可选)] → [AP/Mesh节点/电脑/电视/...]
               ↓
          (光信号转电信号)  (拨号+NAT+DHCP)  (网口不够时扩展)

每个设备各司其职，缺一不可。

光猫（ONT/Modem）

作用：光纤信号 → 网线信号

运营商给你的，把光纤里的光信号转换成网线能用的电信号。

关键指标：

  • 千兆光猫（GPON）：支持千兆宽带
  • 万兆光猫（XG-PON/10G-EPON）：支持>千兆宽带

光猫桥接 vs 光猫拨号：

  • 光猫拨号：光猫负责拨号+NAT → 性能差，不推荐
  • 光猫桥接：光猫只做光电转换，路由器负责拨号 → 推荐！

改桥接：打运营商电话或找装维师傅，说"我要用自己的路由器拨号"

路由器（Router）

作用：拨号上网 + NAT转换 + 分配内网IP + WiFi信号

路由器是家庭网络的大脑。你买的小米/TP-LINK/华硕就是它。

一体机 = 路由器 + 交换机(多个LAN口) + AP(WiFi天线)

分立方案 = 有线路由器 + PoE交换机 + AP面板（更专业）

交换机（Switch）

作用：网口不够用？加个交换机就多了

场景：路由器只有4个LAN口，但你有6台设备要插网线 → 加一个8口千兆交换机

傻瓜交换机（非管理型）：即插即用，不需要配置，价格30-100元
网管交换机（管理型）：可以设VLAN/链路聚合/限速，价格200-1000元
PoE交换机：网线同时供电+传数据（给AP/摄像头供电），价格100-500元

普通家用买个千兆傻瓜交换机（5口/8口）就够了，50块钱搞定。

AP（无线接入点）

作用：只发射WiFi信号，不管拨号/NAT

AP = 纯WiFi发射器，需要搭配路由器/AC控制器使用。

类型：

  • 吸顶AP：装在天花板，覆盖广（客厅/走廊）
  • 面板AP：装在86底盒上，替代网口面板（每个房间一个）
  • 室外AP：庭院/阳台覆盖

AC控制器：管理多个AP的统一平台（设置WiFi名、漫游阈值、信道分配）

你家需要哪些设备？

```

普通家庭（最简方案）：

光猫桥接 → 普通WiFi路由器（一体机） → 搞定！

大户型/复式：

光猫桥接 → 主路由 → PoE交换机 → 吸顶AP + 面板AP

或：

光猫桥接 → Mesh主节点 → Mesh子节点(有线回程)

极客玩家：

光猫桥接 → 软路由 → PoE交换机 → AP

→ NAS

🧩 核心记忆： 光猫（光电转换）、路由器（大脑/NAT/DHCP）、交换机（扩展网口）、AP（纯WiFi发射器）。普通家用买一体机就够了，大户型考虑AC+AP或Mesh方案。光猫改桥接是提升网络体验的第一步（免费！）。
