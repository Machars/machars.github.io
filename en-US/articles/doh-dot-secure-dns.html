什么是DoH/DoT安全DNS？—— 给DNS查询穿上"隐身衣"

传统DNS是明文传输？运营商能看到我访问了哪些网站？DoH和DoT如何保护隐私？

传统DNS的问题

场景：传统DNS = 在大街上大声问路

你问："请问小红家在哪？"（DNS查询）→ 答："中山路100号"（DNS回复）

问题是大街上所有人都听到了——运营商知道你访问了哪个网站，中间经过的网络节点也能看到你的DNS查询。这就是DNS明文传输的隐私问题。

DoH/DoT = 用加密的耳语问路

你小声问（加密），回答也小声（加密）。旁边人（运营商）看到你在"说话"，但不知道你在说什么。

DoH vs DoT

DoH(DNS over HTTPS)DoT(DNS over TLS)
------------------
端口443（和HTTPS一样）853（专用端口）
伪装看起来就是普通HTTPS流量是独立的TLS流量
防火墙极难被封可能被屏蔽853端口
推荐个人设备路由器层面部署

如何开启DoH/DoT

Chrome/Edge浏览器：
设置 → 隐私和安全 → 安全 → 使用安全DNS → 选择"自定义"
→ 填入 https://dns.alidns.com/dns-query（阿里DoH）
→ 或 https://doh.pub/dns-query（腾讯DoH）

路由器层面（部分品牌支持）：
TP-LINK: 网络设置 → DNS → DNS over HTTPS
华硕: WAN设置 → DNS Privacy Protocol → DoT
小米: 部分新固件支持，在DNS设置里找

Win11: 设置 → 网络 → WiFi属性 → DNS服务器分配 → 支持DoH

DoH会影响网速吗？

加密多了一道"包裹"过程，理论上多几毫秒——但实际感知几乎没有。隐私保护的好处远大于这点延迟。

🔐 核心记忆： 传统DNS是"明码问路"，DoH/DoT是"加密耳语"。开启后运营商只能看到你在上网，但看不到你访问了哪些网站。推荐开启，Chrome/Edge都内置支持。
