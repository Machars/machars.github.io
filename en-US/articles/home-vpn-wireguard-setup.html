VPN回家 vs 端口转发：选哪个？

场景：一个人在家 vs 把你家门钥匙给了所有人
  • 端口转发 = 把你家家门钥匙给了每个想进你家的人（NAS、监控、远程桌面各开一个门）
  • VPN回家 = 只给你自己一把万能钥匙，你拿着钥匙回家后，所有房间随便进

VPN的优势：只开一个端口（VPN端口），就能访问家里所有的设备和服务。安全性是端口转发的N倍。

对比维度端口转发VPN回家
---------------------------
开放端口数每个服务一个只一个VPN端口
安全性⭐⭐⭐⭐⭐⭐⭐
速度⭐⭐⭐⭐⭐(无加密开销)⭐⭐⭐⭐(轻量加密)
配置复杂度⭐⭐⭐⭐⭐
维护成本中等低(配好基本不用管)

WireGuard vs OpenVPN：该选哪个？

特性WireGuardOpenVPN
--------------------------
速度⚡ 接近裸线速度🐢 中等(加密开销大)
CPU占用极低较高
配置⭐ 简单(一个配置文件)⭐⭐⭐ 复杂(要管理证书)
协议UDP onlyTCP/UDP可切换
客户端全平台(Win/Mac/iOS/Android)全平台
路由器支持新路由器越来越多几乎所有路由器都支持
推荐场景日常回家、性能优先特殊网络环境(需TCP伪装)

🎯 选择建议：2024年起优先WireGuard。只有在UDP被封锁的特殊网络环境下(某些企业WiFi/校园网)，才考虑OpenVPN的TCP模式。

WireGuard完整搭建（OpenWrt路由器版）

前置条件：
  • 路由器刷了OpenWrt（或其他支持WireGuard的固件）
  • 有公网IP + DDNS域名
  • 已配置好端口转发（或路由器直接是出口）
第一步：安装WireGuard

``bash

# SSH登录OpenWrt

ssh root@192.168.1.1

# 安装

opkg update

opkg install wireguard-tools luci-app-wireguard


第二步：配置服务端（路由器）

进入OpenWrt后台 → 服务 → WireGuard → 添加接口：

[Interface]

监听端口 = 51820

私钥 = (点击"生成密钥对"自动生成)

IP地址 = 10.0.0.1/24

MTU = 1420


添加Peer（给手机/电脑的连接配置）：

[Peer]

公钥 = (客户端生成的公钥)

允许的IP = 10.0.0.2/32


防火墙放行：

网络 → 防火墙 → 通信规则 → 添加

名称：WireGuard / 协议：UDP / 端口：51820 / 动作：接受


第三步：配置客户端（手机/电脑）

在手机上下载WireGuard APP，创建配置：
ini

[Interface]

PrivateKey = (客户端自动生成的私钥)

Address = 10.0.0.2/24

DNS = 192.168.1.1

[Peer]

PublicKey = (服务端公钥，从路由器复制)

Endpoint = myhome.tpddns.cn:51820

AllowedIPs = 10.0.0.0/24, 192.168.1.0/24

PersistentKeepalive = 25




关键配置解读：

  • AllowedIPs = 192.168.1.0/24 → 只把访问家里的流量走VPN(分流模式，上网不受影响)
    • 

  • AllowedIPs = 0.0.0.0/0 → 所有流量走VPN(全局模式，上网速度受家里宽带限制)
    • 

  • 推荐用分流模式，不影响你正常上网，只在内网访问时走VPN
    • 



第四步：测试连接
  • 手机关WiFi，用流量
  • 打开WireGuard APP → 点击连接
  • 浏览器访问 192.168.1.1 → 看到路由器后台 ✅
  • 访问NAS 192.168.1.100:5000 → 看到群晖登录页 ✅


在群晖NAS上搭WireGuard（更简单）


如果你没有OpenWrt路由器但有群晖NAS：

套件中心 → 安装「VPN Server」→ 选择WireGuard

设置端口(如51820) → 导出客户端配置文件

手机上导入配置 → 搞定！



OpenVPN搭建（兼容所有路由器）


如果路由器不支持WireGuard或者你需要TCP模式：
bash

# OpenWrt安装OpenVPN

opkg update

opkg install openvpn-openssl luci-app-openvpn easy-rsa


核心配置文件：

# /etc/openvpn/server.conf

port 1194

proto tcp # TCP模式可走443端口伪装HTTPS流量

dev tun

server 10.8.0.0 255.255.255.0

push "route 192.168.1.0 255.255.255.0"

push "dhcp-option DNS 192.168.1.1"

cipher AES-256-GCM



VPN回家后的"魔法"——你能做什么？



操作使用方式
---------------
访问NAS文件打开群晖DS File，直接输入内网IP 192.168.1.100
远程桌面Windows按Win+R输入 mstsc → 输入家里电脑IP
看监控海康/大华APP输入摄像头的内网IP
打印文件在家里的网络打印机上远程打印
管理路由器浏览器直接访问 192.168.1.1
管理智能家居Home Assistant输入内网IP

所有操作就像你在家里一样——这就是VPN回家的魔力。


安全加固



  • 非标准端口：把51820改成5xxxx范围的高位端口，减少扫描
    • 

  • 密钥轮换：每半年重新生成一次密钥对
    • 

  • 最小权限：客户端AllowedIPs只配置家庭网段
    • 

  • 监控日志：定期检查VPN连接记录，发现异常Peer立刻禁用
    •

手机扫码 → 自动配置 → 连接

全程5分钟
