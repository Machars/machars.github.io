DNS为什么影响网速？

场景：你打开淘宝要经过几步？
  • 你输入 taobao.com → 电脑问DNS："这个域名的IP是多少？"
  • DNS回答："淘宝各地有很多服务器，你在广州，最近的在深圳：47.xx.xx.xx"
  • 浏览器用这个IP连接深圳服务器，淘宝秒开

如果DNS慢(500ms才回答)、DNS瞎指路(把你指向北京服务器)、DNS被劫持(指向了广告服务器) → 网页打开就慢。

怎么改DNS？

在路由器上改（全局生效，推荐）： 
路由器后台 → DHCP设置 → DNS
从"自动获取"改为"手动"
首选：223.5.5.5  备用：119.29.29.29
保存 → 设备重连WiFi生效

DNS劫持检测和解决

``bash

# 用不同DNS查询同一域名

nslookup www.example.com 223.5.5.5

nslookup www.example.com 8.8.8.8

# 返回不同IP → 其中一个DNS被劫持

``

解决：换DNS。运营商劫持一般只劫持运营商自己的DNS。

加密DNS：DoH/DoT防止偷窥

普通DNS查询是明文的。DoH/DoT给它加密：

  • Chrome: 设置 → 安全 → 使用安全DNS → Cloudflare
  • Firefox: 设置 → 网络设置 → 启用基于HTTPS的DNS

AdGuard Home：终极DNS方案

在NAS/软路由上部署AdGuard Home：

  • 全局广告过滤(APP广告也能拦)
  • DNS缓存加速(高频域名<1ms响应)
  • 可视化面板
  • 可在群晖Docker中一键部署

🚀 DNS优化实测： 阿里DNS + AdGuard Home缓存，常用网站DNS查询延迟从40ms降到<1ms，网页白屏时间缩短60%。
