Restart vs Reset

ActionRestartReset
------------------------
WiFi PasswordUnchangedDefault
Internet SettingsUnchangedCleared
Admin PasswordUnchangedDefault
All ConfigUnchangedCleared

When to Restart?

  • Internet suddenly slow
  • Some devices can't connect
  • After long uptime (every 1-2 weeks)

How to Restart

  • App: Device → Reboot
  • Web: System → Reboot
  • Physical: Unplug 10s, replug

When to Reset?

  • Forgot admin password
  • Configuration messed up
  • Selling router
  • After failed firmware upgrade

How to Reset

  • Router powered on
  • Hold Reset pinhole 5-10 seconds
  • All LEDs flash, release
  • Wait for reboot

> Reset means you need to set up from scratch!
