Basic Security

Change Admin Password

  • 10+ characters, mixed case + numbers + symbols

Disable WPS

  • Security → WPS → Disable

Set WPA2/WPA3

  • Wireless → Encryption → WPA2-PSK(AES)

Firewall

SPI Firewall

  • Security → Firewall → Enable (default)

DoS Protection

  • Advanced Security → Enable

Access Control

MAC Filtering

  • Whitelist: Only listed devices
  • Blacklist: Block listed devices

IP & MAC Binding

  • Prevents ARP spoofing

Additional

  • Disable remote management
  • Change passwords regularly
  • Check connected devices periodically
