为什么需要知道默认地址和密码？

每个路由器出厂时都有一个默认管理地址和默认登录账户，只有知道这些才能进入后台进行WiFi设置、密码修改等操作。如果你忘记了自定义的管理密码，重置路由器后也需要用到默认密码。

最常见的路由器默认IP

市面上90%的路由器使用以下两个默认IP之一：

  • 192.168.0.1 — TP-LINK、D-Link、腾达、360
  • 192.168.1.1 — TP-LINK（部分型号）、华硕（部分）、网件、水星、Linksys

如果你不确定，可以在电脑上查看「默认网关」：

  • Windows：打开CMD，输入 ipconfig，找到"默认网关"那一行
  • Mac：系统设置 → 网络 → Wi-Fi → 详细信息 → 路由器
  • 手机：WiFi设置 → 点击已连接的WiFi → 查看"路由器"或"网关"

忘记密码怎么办？

步骤1：先试底部标签

翻看路由器底部，很多路由器在标签上印了默认管理地址和登录信息。

步骤2：恢复出厂设置

如果标签上没有或你改过了密码：

  • 路由器通电（不要拔网线）
  • 用牙签/卡针按住路由器背面的 Reset 小孔
  • 持续按住 5-10秒，直到所有指示灯同时闪烁
  • 松开，等待路由器重启（约1-2分钟）
  • 此时路由器已恢复出厂，可使用默认地址和默认密码登录
  • 重新设置WiFi名称、密码和上网参数

> 🔄 恢复出厂设置后，所有自定义配置都会丢失，需要像新买来一样重新设置！

为什么不同品牌用不同地址？

不同品牌选择不同的管理IP，主要是为了避免 IP地址冲突。

比如你家光猫用 192.168.1.1，如果路由器也用 192.168.1.1，两者就会打架。所以很多厂商选择偏门地址：

  • 小米选 192.168.31.1 — 和常见的.0.1、.1.1都不冲突
  • 华为选 192.168.3.1 — 同理
  • 锐捷选 192.168.110.1 — 不按常规出牌

域名 vs IP 哪个更好？

现在很多厂商用域名代替IP（如 tplogin.cn、miwifi.com）：

  • ✅ 记域名更方便，不用记一串数字
  • ✅ 即使改了IP也能访问（域名会自动解析到路由器）
  • ❌ 少数老路由器不支持域名，只能用IP

🏠 核心记忆： 找不到路由器后台入口？先看路由器底部标签 → 不行就用电脑查"默认网关" → 还不行就恢复出厂设置。国内最常用的是 192.168.0.1 和 192.168.1.1，记得先试这两个。
